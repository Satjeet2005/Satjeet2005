## Featured work

### [Model Change Review Lab](https://github.com/Satjeet2005/model-change-review-lab)

A full-stack engineering prototype exploring safe review and application of financial-model changes.

- **Proposal-first workflow:** inspect before/after operations before changing canonical state.
- **Correctness controls:** atomic commits, revision-aware stale-change protection, and persisted transaction history.
- **Explainability:** trace calculated outputs through a dependency DAG to their formulas and inputs.
- **Engineering practice:** React + TypeScript, FastAPI, PostgreSQL, automated tests, and a documented CI/deployment workflow.

*The proposal provider is deterministic and local; the project uses synthetic data and does not call a live LLM.*
